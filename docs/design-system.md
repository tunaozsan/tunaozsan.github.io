# Bluefin Tuna design system

Marine navy (#061224), ice (#edf3f6), cyan (#52cdee), muted blue-grey, and restrained borders. System sans typography with Georgia italic display accents. No remote fonts, analytics, animation libraries, or decorative image downloads.

Original supplied logo is retained at assets/brand/bluefin-tuna-master.png locally. Optimized 1000px WebP (23.7 KB) and 320px WebP (6.4 KB) are served. Artwork and colors are unchanged; CSS positions the original lockup inside the hero composition. Legacy assets/company-logo.png is preserved through the original GitHub tree.

Shared components: primary navigation with nonmodal mobile disclosure, visible keyboard focus, skip link, buttons, section headings, division panels, service cards, comparison tables, native details FAQs, light legal reading surface, app rows, direct email support and footer. English-only launch; no fake language selector or placeholder localized pages. Illustrative schedule data is labeled, never presented as client work.

Responsive layout uses 767/1099/1199px breakpoints. Decorative motion is absent; hover transitions and smooth scrolling are disabled under prefers-reduced-motion. Essential content and contact routes are server-served HTML.
